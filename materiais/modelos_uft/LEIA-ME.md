# materiais/modelos_uft/ — modelos institucionais da UFT

Coloque aqui os seis arquivos abaixo, com estes nomes exatos (são os nomes que estavam no
Projeto "PROJETO BIBLIODOCS-PRO" do claude.ai, de onde podem ser baixados):

1. `Modelo de TCC de graduação - Atualizado 2022.doc`
2. `Template de Artigo - Atualizado 2022.doc`
3. `Template de Dissertação - Atualizado 2022.doc`
4. `Template de Tese - Atualizado 2022.doc`
5. `Template de Relatório Técnico - Atualizado 2022.doc`
6. `Template de Projeto de pesquisa - Atualizado 2022.doc`

**Por que não vieram no ZIP:** na preparação do kit só a extração de texto desses modelos estava
acessível, não os arquivos `.doc`. Sem o arquivo original não há como estudar estilos, margens e
campos do Word, e o kit não cria cópias simuladas.

**Como o Claude Code os usa (Etapa 3):** os modelos são exemplos institucionais, não norma.
Servem para comparar estrutura e apresentação com o Manual. Divergências entre modelo e Manual
são registradas; o Manual prevalece (ver `docs/POLITICA_DE_FONTES_NORMATIVAS.md`).
Arquivos `.doc` (formato binário antigo) podem exigir conversão para `.docx` em `analise/`
(LibreOffice em modo headless ou Word); o Claude Code pedirá autorização antes de instalar algo.
