# analise/ — área de trabalho do Claude Code

Extrações e cópias de trabalho dos originais de `materiais/` (por exemplo,
`analise/sistema_original_extraido/`, conversões `.doc → .docx`, documentos de amostra gerados
pelo sistema antigo). Tudo aqui pode ser apagado e recriado; por isso a pasta é ignorada pelo git
(exceto este arquivo). Nunca guarde aqui a única cópia de algo importante.
